Course files and study notes for BIO220 at XJTLU.

## Materials

| Folder | Contents |
|---|---|
| [Lecture slides](lectures/README.md) | Seven lecture PDFs |
| [Coursework](coursework/README.md) | Two CW1 files, a link to the CW2 project, and one CW3 PDF |

## How to use

1. Open a folder above and choose a file.
2. View the PDF on GitHub, or use the download button to save it.
3. To save the whole collection, select **Code → Download ZIP** at the top of this page.

The [CW2 project](https://github.com/Ci-yo/BIO220_CW2_MOR-Structure) has its own repository. Open that link to view its files and instructions.
